Библиотека ndVpi — это мощный инструмент для диагностики, мониторинга и агрессивной оптимизации сети. В бета-версии 1.0.1b3 добавлен новый масштабный инструмент RouteTracer (продвинутый анализатор маршрутов). В отличие от стандартного tracert, он замеряет задержку на каждом узле (роутере провайдера, магистральных узлах), вычисляет потери пакетов на конкретных хопах и показывает, на каком именно участке сети происходят проблемы (у вас дома, у провайдера или на сервере игры). Отчет можно экспортировать в красивую таблицу через CharmPkk.



Оптимизатор разделен на два модуля: Polidium и Critchers. Polidium отвечает за безопасную очистку (сброс DNS, ARP, кэша маршрутов) и умную оптимизацию. Теперь он включает в себя DNS-Бенчмарк, который автоматически пингует популярные DNS-серверы (Cloudflare, Google, Quad9) и подсказывает, какой из них самый быстрый прямо сейчас. Critchers — это агрессивный сетевой бустер, который выполняет скрытую работу. Он очищает невидимый кэш оперативной памяти (Standby List), кэш NetBIOS, освобождая ресурсы для сетевых драйверов. С помощью правки реестра Windows (требуются права Администратора) он отключает алгоритмы задержки TCP и ускоряет сброс зависших пакетов, что снижает пинг в играх и стримингах. Все изменения реестра бэкапятся, и их можно откатить одной командой restore.



Интерфейс меню был полностью переработан. Теперь это интерактивный дашборд, который сразу отображает IP-адрес, шлюз, текущий пинг и наличие прав администратора, а все функции разбиты по логическим категориям: Сеть, Оптимизация и Инструменты. Монитор в реальном времени отрисовывает графики пинга (спарклайны) прямо в консоли. Если у вас установлена библиотека CharmPkk, весь интерфейс автоматически окрашивается в красивые градиентные цвета и использует плавную перерисовку Live без мерцания.



Для установки используйте команду pip install ndVpi. Для интеграции с красивым интерфейсом CharmPkk используйте pip install "ndVpi\[charm]". Обратите внимание, что функции Critchers (очистка RAM, твики реестра) работают только на Windows и требуют запуска консоли от имени Администратора.
