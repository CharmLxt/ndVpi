ndVpi. Версия 2.101.0. Автор CharmLxt (PyPI: CharmLxt, email: reception.mailspypi@gmail.com). Ссылка на GitHub: https://github.com/CharmLxt/ndVpi.



Библиотека ndVpi — это мощный инструмент для диагностики, мониторинга и агрессивной оптимизации сети. В версии 2.101.0 мы провели масштабную работу над ошибками, улучшили стабильность и добавили интеграцию с новыми проектами.



Модуль Polidium отвечает за безопасную очистку и умную оптимизацию. Он очищает системный DNS-кэш, ARP-таблицы и кэш маршрутов, устраняя ошибки маршрутизации. В него встроен DNS-Бенчмарк, который автоматически пингует популярные DNS-серверы (Cloudflare, Google, Quad9) и подсказывает, какой из них самый быстрый прямо сейчас.



Модуль Critchers — это агрессивный сетевой бустер. Он очищает кэш оперативной памяти (Standby List) и кэш NetBIOS, освобождая ресурсы для сетевых драйверов. С помощью правки реестра Windows (требуются права Администратора) он отключает алгоритмы задержки TCP и ускоряет сброс зависших пакетов. В версии 2.101.0 исправлен баг с восстановлением: если вы приостанавливали фоновые загрузки (OneDrive и другие), команда Restore теперь гарантированно их возобновляет, а не оставляет висеть в памяти.



Для разработчиков и тестировщиков добавлен модуль NetworkOptimizer. Раньше он был скрыт внутри системы, но теперь вы можете вызвать метод optimize\_for\_streaming(). Он включает агрессивное кэширование DNS и отключает алгоритм Нейгла для сокетов, что критически важно для приложений с низкой задержкой, таких как удаленный рабочий стол или стриминг видео.



Меню библиотеки стало еще удобнее. В интерактивном дашборде теперь корректно отображается пинг, даже если сервер временно не отвечает (раньше программа могла упасть с ошибкой). Исправлен баг с графиками sparkline в консольном режиме: теперь они не крашатся, если все значения равны нулю.



Отдельное внимание уделено интеграции с терминалом Collquan. Раньше в нем было доступно только 11 команд, теперь их 16. Добавлены: ndopt (быстрая оптимизация под стриминг), ndstatus (проверка задержки DNS-серверов), nddiag (полная диагностика с рекомендациями), ndlive (короткий мониторинг сети на 5 секунд) и ndexport (сохранение истории сессии в JSON).



Как и прежде, библиотека мягко интегрируется с CharmPkk: если он установлен, весь интерфейс окрашивается в красивые цвета и использует плавную перерисовку Live без мерцания. Если нет — работает на чистом print. Установка: pip install ndVpi. Для интеграции с красивым интерфейсом CharmPkk используйте pip install "ndVpi\[charm]". Обратите внимание, что функции Critchers (очистка RAM, твики реестра) работают только на Windows и требуют запуска консоли от имени Администратора. Связь с автором: reception.mailspypi@gmail.com.
